# Checklist 50 câu — phụ trách: Quang (A)

Checklist GUI theo control do GVTH giới thiệu, áp dụng trên luồng Checkout của EShop.

**Cần nộp:**
1. `checklist-50.md` — đủ 50 câu, mỗi câu có kết quả + ảnh nếu Fail.
2. Phân loại mỗi câu: **Tự động** (Playwright/axe kiểm được) · **Bán tự động** · **Thủ công**. Câu "Tự động" đưa vào `tests/playwright/data/`.
3. Lỗi Fail mới → thêm vào `ground-truth/bugs.md`.
4. Bản rút gọn kèm đáp án → `exercises/` (C đưa vào bài tập).
5. Phần nội dung slide: `content/03-checklist.md`.

Ảnh minh chứng: `evidence/checklist/`.
